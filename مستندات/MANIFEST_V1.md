# مواصفة `takween-manifest-v1`

> **الحالة:** الأهداف المتعددة والاختبارات واعتماديات المسار وGit المثبتة وlock-v1 منفذة؛ globs/SemVer/workspace planning لاحقة
> **الملف القياسي:** `مشروع.تكوين`

## الغرض

تستبدل v1 الصيغة المسطحة المؤقتة ببيان وصفي typed يدعم عدة أهداف وأنماط
واعتماديات ومساحات عمل دون أن يتحول إلى لغة برمجة أو shell script.

## القواعد المعجمية

- UTF-8 صالح فقط، مع LF كخرج قياسي للأدوات.
- التعليقات تبدأ بـ `//` خارج النصوص.
- الأقسام تكتب `[اسم]` أو `[أب.ابن]`.
- الإسناد `مفتاح = قيمة`.
- القيم الأولى: نص quoted، صحيح عشري، منطقي `صواب/خطأ`، ومصفوفة متجانسة.
- الأسماء والمفاتيح العربية قياسية؛ لا aliases إنجليزية داخل البيان.
- المفتاح أو القسم المجهول خطأ، ولا توجد interpolation أو أوامر قابلة للتنفيذ.

## مثال

```text
[المشروع]
الاسم = "تطبيقي"
الإصدار = "1.0.0"
إصدار_باء = ">=0.7.0 <0.8.0"
الترخيص = "MIT"

[الأهداف.تطبيقي]
النوع = "تنفيذي"
المدخل = "المصدر/الرئيسية.baa"
المصادر = ["المصدر/**/*.baa"]
مسارات_التضمين = ["ترويسات"]

[البناء]
المخرج = "بناء"
الهدف = "x86_64-windows"
النمط = "تطوير"

[الأنماط.تطوير]
التحسين = 0
التحقق = صواب

[الأنماط.إصدار]
التحسين = 2
التحقق = صواب

[الاعتماديات.سلاسل]
الإصدار = "^2.1.0"

[الاعتماديات.هندسة]
المسار = "../هندسة"

[الاعتماديات.شبكة]
git = "https://example.invalid/network.git"
commit = "0123456789abcdef0123456789abcdef01234567"

[مساحة_العمل]
الأعضاء = ["حزم/*"]
```

## العقود

## حالة التنفيذ الحالية

- يكتشف parser v1 عندما يبدأ أول سطر فعال بـ `[`، ولا يعيد تفسير 0.1 بصمت.
- منفذ: النص quoted مع escapes محددة، الصحيح `0..2`/الأرقام العربية للتحسين،
  `صواب/خطأ`، ومصفوفات النصوص المتجانسة، والتعليق `//` خارج النص.
- منفذ: `[المشروع]` وعدة أقسام `[الأهداف.<اسم>]` بأنواع `تنفيذي/اختبار/مكتبة`
  و`[البناء]` و`[الأنماط.<اسم>]`؛ build/check/run تقبل اسم هدف اختياري.
  واعتماديات `المسار` أو `git` + `commit` وقراءة typed لـ `[مساحة_العمل]`.
- اعتماديات المسار وGit تقرأ بيان v1 للحزمة، وتضيف مصادرها ومسارات تضمينها بصورة
  متعدية، وترفض الدورة المباشرة/المكررة. الحد الدفاعي للعمق 16.
- Git يقبل commit lowercase hex مثبتا بطول 40 أو 64 فقط؛ branch/tag أو خلط
  `المسار` مع Git خطأ manifest. checkout يمر عبر Process API بلا shell.
- check/build/run تكتب `تكوين.قفل` بصيغة `takween-lock-v1` مرتبة وحتمية، مع
  المشروع وهدف Baa وعقد الحزم وعلاقات parent والمصدر وcommit.
- غير منفذ: globs، بناء المكتبة المستقلة، DAG workspace، registry، SemVer resolver،
  archive hashes، والترحيل الآلي. ظهور اعتماد إصدار يفشل برسالة `غير مدعوم بعد`.
- أي قسم أو مفتاح أو نوع قيمة مجهول خطأ؛ لا توجد lifecycle scripts أو shell.

### المشروع

- `الاسم` و`الإصدار` و`إصدار_باء` إلزامية للحزمة القابلة للنشر.
- الإصدار Semantic Versioning صالح.
- `الترخيص` معرف SPDX عند النشر.

### الأهداف

- الأنواع الأولى: `تنفيذي` و`مكتبة` و`اختبار`.
- `المدخل` ملف `.baa` واحد عند الحاجة؛ `المصادر` توسع إلى roots إضافية.
- ترتيب الملفات بعد globs حتمي حسب مسار UTF-8 المطبع.
- لا يسمح لمسار أو symlink بالخروج من جذر الحزمة دون اعتماد `مسار` صريح.

### الأنماط

- يرث الهدف النمط المحدد في `[البناء]` ويمكن CLI أن يختار نمطا آخر.
- الحقول المعروفة تتحول إلى أعلام Baa؛ لا يوجد حقل flags حر في v1.

### الاعتماديات

- الاعتمادية تحدد واحدا فقط من `الإصدار` أو `المسار` أو Git المثبت؛ Git المثبت
  يكتب بحقل `git` وحقل `commit` دقيقين.
- resolver الحالي يكتب المصدر وcommit/المسار الدقيقين في `تكوين.قفل`. يضاف
  اختيار SemVer وhash archive عندما تنفذ حزم registry.
- لا تنفذ الحزمة أوامر install/build ضمنية.

## الترحيل من 0.1

يوفر `تكوين ترحيل` معاينة ثم كتابة ذرية:

- الحقول العامة تنتقل إلى `[المشروع]` و`[البناء]`.
- `ملفات` تصبح `المصادر` بعد تحويل كل عنصر إلى نص quoted.
- `مكتبات` لا تخمن؛ يطلب المستخدم تحديد `مسار` أو `إصدار` لكل عنصر.
- `أعلام_إضافية` تظهر كتحذير ويتطلب كل علم حقلا typed معروفا أو قرارا يدويا.
- يحتفظ الملف القديم بنسخة احتياطية ولا يكتب v1 إذا بقيت قيمة غامضة.

## إصدارات الصيغة

رقم إصدار Takween لا يساوي إصدار البيان. أي حذف مفتاح، تغيير معنى، أو تحويل
قيمة مقبولة إلى معنى آخر يتطلب schema major جديدا وأداة ترحيل.
