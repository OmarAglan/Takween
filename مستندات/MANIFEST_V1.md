# مواصفة `takween-manifest-v1`

> **الحالة:** الأهداف المتعددة والاختبارات واعتماديات المسار وGit المثبتة
> والإصدار المحلي وSemVer والأرشيف الآمن والتوريد وlock-v1 وDAG الأهداف
> وأنماط `تطوير/إصدار` القابلة للتوسعة ومساحات العمل متعددة الحزم منفذة؛
> globs وحواف أعضاء مساحة العمل المستنتجة لاحقان.
> **الملف القياسي:** `مشروع.تكوين`

## الغرض

تستبدل v1 الصيغة المسطحة المؤقتة ببيان وصفي typed يدعم عدة أهداف وأنماط
واعتماديات ومساحات عمل دون أن يتحول إلى لغة برمجة أو shell script.

## القواعد المعجمية

- UTF-8 صالح فقط، مع LF كخرج قياسي للأدوات.
- التعليقات تبدأ بـ `//` خارج النصوص.
- الأقسام تكتب `[اسم]` أو `[أب.ابن]`.
- الإسناد `مفتاح = قيمة`.
- القيم الأولى: نص quoted، صحيح عشري، منطقي `صواب/خطأ`، ومصفوفة متجانسة.
- الأسماء والمفاتيح العربية قياسية؛ لا aliases إنجليزية داخل البيان.
- المفتاح أو القسم المجهول خطأ، ولا توجد interpolation أو أوامر قابلة للتنفيذ.

## مثال

```text
[المشروع]
الاسم = "تطبيقي"
الإصدار = "1.0.0"
إصدار_باء = ">=0.6.0 <0.7.0"

[الأهداف.تطبيقي]
النوع = "تنفيذي"
المدخل = "المصدر/الرئيسية.baa"
المصادر = ["المصدر/مساعد.baa"]
مسارات_التضمين = ["ترويسات"]
يعتمد_على = ["حساب"]

[الأهداف.حساب]
النوع = "مكتبة"
المدخل = "المصدر/حساب_مكتبة.baa"

[البناء]
المخرج = "بناء"
الهدف = "x86_64-windows"
النمط = "تطوير"
المجمع = "نظم"

[الأنماط.تطوير]
التحسين = ١
التحقق = صواب

[الأنماط.إصدار]
التحسين = ٢
التحقق = صواب

[الاعتماديات.سلاسل]
الإصدار = "^2.1.0"

[الاعتماديات.هندسة]
المسار = "../هندسة"

[الاعتماديات.شبكة]
git = "https://example.invalid/network.git"
commit = "0123456789abcdef0123456789abcdef01234567"

[مساحة_العمل]
الأعضاء = ["حزم/حساب", "حزم/تطبيق"]
```

## العقود

## حالة التنفيذ الحالية

- يكتشف parser v1 عندما يبدأ أول سطر فعال بـ `[`، ولا يعيد تفسير 0.1 بصمت.
- منفذ: النص quoted مع escapes محددة، الصحيح `0..2`/الأرقام العربية للتحسين،
  `صواب/خطأ`، ومصفوفات النصوص المتجانسة، والتعليق `//` خارج النص.
- منفذ: `[المشروع]` وعدة أقسام `[الأهداف.<اسم>]` بأنواع `تنفيذي/اختبار/مكتبة`
  و`[البناء]` و`[الأنماط.<اسم>]`؛ build/check/run تقبل اسم هدف اختياري.
  الحقل `يعتمد_على` يبني DAG مكتبات حتميا ويكشف الدورة بالمسار الكامل.
  واعتماديات `المسار` أو `git` + `commit` أو `الإصدار` وقراءة typed
  لـ `[مساحة_العمل]` مع مسارات أعضاء صريحة.
- اعتماديات المسار وGit تقرأ بيان v1 للحزمة، وتضيف مصادرها ومسارات تضمينها بصورة
  متعدية، وترفض الدورة المباشرة/المكررة. الحد الدفاعي للعمق 16.
- Git يقبل commit lowercase hex مثبتا بطول 40 أو 64 فقط؛ branch/tag أو خلط
  `المسار` مع Git خطأ manifest. checkout يمر عبر Process API بلا shell.
- اعتماديات `الإصدار` تحل أعلى SemVer مطابق من `takween-index-v1` المحلي المحدد
  في `TAKWEEN_PACKAGE_INDEX`، وتتحقق من SHA-256، ثم تفك `takween-archive-v1`
  الآمن إلى cache معنون بالتجزئة وتطابق اسم/إصدار الحزمة.
- check/build/run تكتب `تكوين.قفل` بصيغة `takween-lock-v1` مرتبة وحتمية، مع
  المشروع وهدف Baa وعقد الحزم وعلاقات parent والمصدر وcommit أو اختيار archive
  الدقيق وقيده وتجزئته، وقيد Baa والهدف والقدرات المطلوبة. `--locked` يتحقق من
  هذا الحل دون تغيير القفل.
- `تحقق --بدون_شبكة` يعيد التحقق من القفل والفهرس والأرشيف وcache دون جلب، و`توريد`
  ينسخ الحزم المحلولة حتميا تحت `مورد/<الاسم>/<الإصدار>/<sha256>`.
- أسماء المشروع والأهداف والحزم وأسماء الاعتماديات عربية فقط؛ الصيغة اللاتينية ليست
  هوية بديلة مقبولة.
- منفذ: فهرس `takween-workspace-v1` وبناء/اختبار عضو واحد أو كل الأعضاء
  بترتيب التصريح، مع عزل cwd والقفل والكاش وتمرير النمط/`--مقفل`.
- غير منفذ: globs، بناء المكتبة المستقلة، حواف أعضاء مساحة العمل المستنتجة،
  registry/network fetch، النشر العام، والترحيل الآلي.
- أي قسم أو مفتاح أو نوع قيمة مجهول خطأ؛ لا توجد lifecycle scripts أو shell.

### المشروع

- `الاسم` اسم عربي فقط، و`الإصدار` و`إصدار_باء` إلزاميان في v1.
- الإصدار Semantic Versioning صالح.
- قيد `إصدار_باء` يطبق على إصدار المصرّف المكتشف قبل البناء.

### الأهداف

- الأنواع الأولى: `تنفيذي` و`مكتبة` و`اختبار`.
- أسماء الأهداف عربية فقط: حروف عربية وأرقام عربية وشرطة سفلية.
- `المدخل` جذر `.baa` أو `.نظم` واحد عند الحاجة؛ `المصادر` توسع إلى جذور
  إضافية من النوعين فقط. لا تقبل الصيغة امتداد GAS لاتينيا.
- `يعتمد_على` مصفوفة أسماء أهداف مكتبة. ترتب العقد depth-first بترتيب التصريح
  وتدخل كل مكتبة مرة واحدة قبل المستهلك. الهدف المفقود أو غير المكتبة خطأ بيان.
- أي دورة ترفض قبل اكتشاف Baa أو إنشاء خطة، ويذكر التشخيص مسار الدورة الكامل.
  الحد الدفاعي لعمق DAG هو 256 عقدة.
- ترتيب الملفات بعد globs حتمي حسب مسار UTF-8 المطبع.
- لا يسمح لمسار أو symlink بالخروج من جذر الحزمة دون اعتماد `مسار` صريح.

### البناء

- `المجمع` اختياري وقيمته العربية `نظم` أو `غاز`.
- `نظم` يمرر اختيار المجمّع إلى Baa، الذي يحل الأمر العربي `نظم` من `PATH`
  ما لم يوجد override صريح في بيئة التكامل.
- غياب الحقل يجعل Takween يثبت نَظْم صراحة في الخطة حفاظا على الحتمية؛
  `غاز` هو الرجوع المقصود فقط. جذور `.نظم` المباشرة تذهب إلى نَظْم عند
  الاختيار الافتراضي أو `المجمع = "نظم"`.
- lock-v1 يسجل قدرة `مصدر_نظم` عندما يختار الهدف نظم أو يحتوي جذور `.نظم`.

### مساحة العمل

- `الأعضاء` مصفوفة غير فارغة من مسارات relative صريحة وفريدة.
- تمنع absolute و`..` وwildcards؛ لذلك لا يفسر v1 `حزم/*` بصمت.
- كل مسار يجب أن يحتوي حزمة `takween-manifest-v1` صالحة باسم عربي فريد.
- مساحات العمل المتداخلة مرفوضة.
- `تكوين مساحة --جسون` يعيد `takween-workspace-v1`، و`بناء/اختبار` يدعمان
  `--حزمة <اسم>` و`--كل_الحزم`.
- المواصفة التنفيذية: [`WORKSPACE_V1.md`](WORKSPACE_V1.md).

### الأنماط

- إذا غاب `النمط` يستخدم v1 النمط المدمج `تطوير`: تحسين `١` مع `التحقق = صواب`.
- النمط المدمج `إصدار` يستخدم تحسين `٢` مع التحقق. يمكن لقسم يحمل الاسم نفسه
  تخصيص أي من القيمتين.
- `[الأنماط.<اسم_عربي>]` يضيف نمطا مخصصا؛ يجب أن يحدد `التحسين` من `٠..٢`،
  و`التحقق` منطقي اختياري افتراضه `خطأ`.
- أسماء الأنماط عربية فقط، وكل حقل يظهر مرة واحدة. المفتاح المجهول خطأ.
- يرث الهدف النمط المحدد في `[البناء]`، ويمكن CLI اختيار آخر عبر
  `--نمط <اسم>`؛ يبقى `--profile` alias توافقيا ولا يغير شرط الاسم العربي.
- الحقول المعروفة تتحول إلى أعلام Baa؛ لا يوجد حقل flags حر في v1. الجمع بين
  تحسين `٠` والتحقق غير صالح لدى Baa، لذلك يرفضه parser قبل التنفيذ.

### الاعتماديات

- الاعتمادية تحدد واحدا فقط من `الإصدار` أو `المسار` أو Git المثبت؛ Git المثبت
  يكتب بحقل `git` وحقل `commit` دقيقين.
- `الإصدار` قيد SemVer كامل. يدعم exact و`=` و`^` و`~` و`<` و`<=` و`>` و`>=`
  و`*` ومقارنات AND المفصولة بمسافات. يتطلب فهرسا محليا ولا يصل إلى الشبكة.
- resolver الحالي يكتب المصدر وcommit/المسار أو اختيار archive الدقيق وSHA-256
  في `تكوين.قفل`، ويعيد تطبيق قيود Baa والهدف للحزم بعد الاستخراج.
- لا تنفذ الحزمة أوامر install/build ضمنية.

## الترحيل من 0.1

يوفر `تكوين ترحيل` معاينة ثم كتابة ذرية:

- الحقول العامة تنتقل إلى `[المشروع]` و`[البناء]`.
- `ملفات` تصبح `المصادر` بعد تحويل كل عنصر إلى نص quoted.
- `مكتبات` لا تخمن؛ يطلب المستخدم تحديد `مسار` أو `إصدار` لكل عنصر.
- `أعلام_إضافية` تظهر كتحذير ويتطلب كل علم حقلا typed معروفا أو قرارا يدويا.
- يحتفظ الملف القديم بنسخة احتياطية ولا يكتب v1 إذا بقيت قيمة غامضة.

## إصدارات الصيغة

رقم إصدار Takween لا يساوي إصدار البيان. أي حذف مفتاح، تغيير معنى، أو تحويل
قيمة مقبولة إلى معنى آخر يتطلب schema major جديدا وأداة ترحيل.
