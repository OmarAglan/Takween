# عقد `takween-workspace-v1`

## الغرض

تجمع مساحة العمل عدة حزم v1 مستقلة تحت بيان جذر واحد. لكل عضو
`مشروع.تكوين` ومجلد مخرج وقفل وكاش محتوى خاص به. لا تدمج مساحة العمل نماذج
parser للحزم ولا تجعل البيان برنامج بناء.

صيغة الجذر:

```text
[مساحة_العمل]
الأعضاء = [
  "حزم/الحزمة_الأولى",
  "حزم/الحزمة_الثانية"
]
```

الأعضاء في v1 مسارات صريحة مرتبة بصيغة `/` canonical. لا يقبل parser مسارا
مطلقا أو `.`/`..` أو فاصلا مكررا أو wildcard أو عضوا مكررا. globs مؤجلة إلى
بندها المستقل، ومساحات العمل المتداخلة مرفوضة.

## الفهرس

```text
تكوين مساحة --جسون
```

يعيد عقدا مستقرا:

```json
{
  "schema_version": "takween-workspace-v1",
  "members": [
    {
      "name": "الحزمة_الأولى",
      "path": "حزم/الحزمة_الأولى",
      "order": 0,
      "has_tests": true
    }
  ]
}
```

- `name`: هوية `[المشروع].الاسم` العربية، ويجب أن تكون فريدة في المساحة.
- `path`: المسار الصريح كما كتبه البيان الجذر، لا مسار مطلق.
- `order`: ترتيب التصريح، وهو ترتيب تنفيذ `--كل_الحزم`.
- `has_tests`: هل يعرّف بيان العضو هدفا من نوع `اختبار`.

الفهرسة parse-only؛ لا تنشئ مخرجا ولا lock ولا تشغل Baa.

## البناء والاختبار الانتقائي

```text
تكوين بناء --حزمة الحزمة_الأولى
تكوين بناء --كل_الحزم
تكوين اختبار --حزمة الحزمة_الأولى
تكوين اختبار --كل_الحزم
```

- اختيار الحزمة بالهوية لا بالمسار.
- لا يختلط `--حزمة` أو `--كل_الحزم` مع اسم هدف؛ هدف العضو الافتراضي يملكه
  بيان العضو.
- `--نمط <اسم>` و`--مقفل` يمران إلى كل عضو كما هما.
- كل عضو ينفذ بالأمر نفسه داخل cwd الخاص به عبر Process API المهيكلة، بلا
  shell أو command string.
- التنفيذ حتمي ومتسلسل بترتيب `الأعضاء`، ويتوقف عند أول كود غير صفري ويحافظ
  على كود `compiler-cli-v1`.
- `اختبار --كل_الحزم` يتجاوز العضو الذي لا يعلن هدف اختبار. اختيار ذلك العضو
  صراحة يعيد `3` كما يفعل `تكوين اختبار` داخل الحزمة.
- البيان الجذر حزمة v1 صالحة للتوافق مع parser الحالي، لكنه لا يبنى ضمن
  عمليات مساحة العمل إلا إذا شغّل المستخدم build العادي بلا selector.

يبقى بناء هدف مكتبة standalone غير منفذ؛ الحزم التنفيذية/الاختبارية تعمل الآن،
وتظل اعتماديات path/Git/archive داخل كل عضو تحت resolver والقفل الحاليين.
لا يستنتج v1 حواف جديدة بين الأعضاء من ترتيب المسارات.

## الملكية والعزل

لا يحتفظ المنفذ بمؤشرات مستعارة من parser بعد قراءة عضو. فهرس المساحة ينسخ
الاسم والمسار وقدرة الاختبار، ثم يشغل عملية جديدة للحزمة. لذلك:

- لا تتسرب globals من parser بين الأعضاء.
- كل lock و`build-cache.json` يبقى داخل العضو.
- فشل عضو لا يغير بقية بيانات الأعضاء ولا يعاد تصنيفه من نص الرسالة.
- `takween-workspace-v1` مطابق بايتيا للمدخل نفسه ولا يحتوي طابعا زمنيا.
