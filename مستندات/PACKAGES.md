# معمارية الحزم في تكوين

> **الحالة:** اعتماديات path وGit المثبتة واعتماديات الإصدار من فهرس محلي،
> وSemVer، وأرشيف `takween-archive-v1` الآمن، وSHA-256، والتوريد، والتحقق دون
> شبكة، وقفل `takween-lock-v1` منفذة. السجل العام والنشر والجلب الشبكي مؤجلة.

## حدود الملكية

- **Baa:** اللغة وABI وامتدادات `.baa/.baahd` و`baalib` وعقود المصرّف،
  وتمرير جذور `.نظم` إلى المجمع المحدد.
- **Nazm:** صيغة `.نظم` العربية وإنتاج ELF64/COFF؛ الأمر الأساسي على `PATH`
  هو `نظم`.
- **Takween:** الحل والقفل وcache وفك الأرشيف والتوريد والبناء.
- **السجل المستقبلي:** metadata والأرشيفات غير القابلة للتغيير وملكية الأسماء.
- **Qalam:** واجهة مرئية لهذه العمليات؛ لا ينفذ resolver مستقلا.

`baalib` ليست حزمة registry. تشحن مع Baa SDK وتتبع توافق المصرّف. لا يحاول
Takween حلها أو توريدها. المكتبات العليا الرسمية يمكن أن تصبح حزما مستقلة بعد
ثبات عقد النشر، لكن لا يوجد public registry في هذه المرحلة.

## ترتيب التنفيذ

1. اعتماديات `مسار` محلية ومتعدية. **منفذ.**
2. اعتماديات Git مثبتة بـ commit دقيق، بلا branch متحرك وبلا shell. **منفذ.**
3. حل SemVer محلي وقفل حتمي لـ path/Git/archive. **منفذ.**
4. أرشيف محلي immutable، وفك محدود، وcache معنون بالتجزئة، وتوريد حتمي،
   وتحقق صريح دون شبكة. **منفذ.**
5. metadata وقيود النشر وسلامة transport. **مؤجل.**
6. سجل عام وخدمة نشر. **مؤجلان صراحة.**

## ملف القفل

`تكوين.قفل` ملف JSON مولد وحتمي بـ UTF-8/LF، وصيغته `takween-lock-v1`. يحتوي:

- إصدار resolver واسم/إصدار المشروع؛
- قيد إصدار Baa، والهدف المختار، والقدرات المطلوبة (`تجميع` في v1)؛
- alias واسم/إصدار كل حزمة وعلاقة `parent` الانتقالية؛
- path المطبع، أو Git URL وcommit الدقيق، أو قيد SemVer والاختيار النصي الدقيق
  ومسار الفهرس والأرشيف وتجزئة SHA-256؛
- ترتيبا canonical للعقد، بحيث تعطي الإعادة نفس البايتات.

في وضع `--مقفل` يكتب resolver مرشحا مؤقتا، يقارنه بايتيا بالقفل الموجود، ثم
يحذفه. لا يستبدل القفل عند التطابق أو الاختلاف. التطبيق يثبت اختياراته بالقفل؛
أما المكتبة فتنشر مجال إصدار وتستخدم قفلا محليا لاختبارات maintainer.

## SemVer والفهرس المحلي

اعتمادية الإصدار تكتب مثلا `الإصدار = "^1.2.0"`. يدعم resolver إصدارات
`major.minor.patch` الكاملة مع prerelease/build metadata، والقيود exact و`=` و`^`
و`~` و`<` و`<=` و`>` و`>=` و`*`. المقارنات المفصولة بمسافة تعني AND. يختار
أعلى precedence مطابق، ثم يستخدم النص الكامل tie-break حتميا عندما تختلف build
metadata ولا تغير precedence.

لا يكتشف Takween سجلا على الشبكة. يحدد المستخدم فهرسا محليا صريحا في
`TAKWEEN_PACKAGE_INDEX`. الملف UTF-8/LF ومفصول بعلامة tab:

```text
takween-index-v1
اسم_الحزمة<TAB>الإصدار<TAB>sha256<TAB>مسار_الأرشيف
```

الاسم عربي وفق عقد الهوية أدناه، والإصدار SemVer كامل، و`sha256` lowercase من
64 خانة. يتحقق Takween من بايتات الأرشيف قبل فكها، ثم يقرأ بيان الحزمة ويتأكد
أن الاسم والإصدار يطابقان اختيار الفهرس. لا يوجد `content_path` موثوق في الفهرس.

## `takween-archive-v1`

الأرشيف ملف UTF-8/LF خطي وحتمي، لا ZIP/TAR ولا أوامر تنفيذ:

```text
takween-archive-v1
ملف<TAB>مسار_نسبي<TAB>عدد_البايتات<TAB>sha256_الملف<TAB>حمولة_hex_lowercase
...
نهاية<TAB>عدد_الملفات<TAB>مجموع_البايتات
```

يجب ترتيب المسارات ترتيبا تصاعديا بلا تكرار. يفك Takween إلى
`.takween/packages/sha256/<sha256-الأرشيف>` ويكتب إيصال
`.تكوين-استخراج-v1` يحفظ تجزئة الأرشيف وتجزئة كل ملف. يعاد فحص الإيصال والملفات
ومقارنتها مباشرة بسجلات الأرشيف الثابت قبل كل استخدام؛ لذلك لا يكفي تزوير الملف
وإيصاله معا، وأي عبث يجعل cache غير صالح.

الحدود الدفاعية الحالية:

- 1024 ملفا كحد أقصى؛
- 8 MiB لكل ملف و64 MiB للمجموع المفكوك؛
- 512 محرفا للمسار، وحد سطر يغطي أكبر حمولة مسموحة؛
- رفض المسار المطلق و`..` و`.` والمقاطع الفارغة وbackslash وcolon؛
- رفض أي سجل ليس `ملف`، ومنه الروابط والأنواع الخاصة؛
- رفض المسار المكرر وتصادم ملف مع مجلد والفرز غير الحتمي؛
- رفض hex أو SHA-256 أو العدد أو الحجم أو trailer الزائد غير المطابق؛
- حذف شجرة الاستخراج المرشحة كاملة عند أي فشل.

## التحقق دون شبكة والتوريد

```text
تكوين تحقق --بدون_شبكة
تكوين توريد
```

`تحقق --بدون_شبكة` يفعّل القفل الصارم، ويطلب cache مستخرجا وصالحا، ولا يصلح
الملفات المتلاعب بها ولا يجلب Git أو شبكة. `توريد` يعمل أيضا من القفل وcache
المحليين، ويحذف `مورد` ثم يعيد إنشاء كل حزمة archive في المسار:

```text
مورد/<اسم_عربي>/<إصدار_دقيق>/<sha256>/...
```

إعادة الأمر بالقفل والمدخلات نفسيهما تنتج أسماء وملفات وتجزئات متطابقة. توريد
Git أو path غير مطلوب في هذا القطع؛ الحزم المنشورة immutable هي وحدة التوريد.

## الهوية العربية والأمان

أسماء المشروع والحزمة وalias الاعتمادية عامة عربية فقط. يقبل v1 حروف العربية
`ء..غ` و`ف..ي`، والأرقام العربية `٠..٩`، والشرطة السفلية، ويشترط حرفا عربيا
واحدا على الأقل. لذلك ترفض الهوية اللاتينية والمختلطة، والحركات، والتطويل، وbidi
controls. المقارنة في v1 بايتية UTF-8؛ تطبيع NFC للسجل المستقبلي قرار صيغة لاحق
ولا يحدث بصمت الآن.

لا توجد lifecycle scripts ضمنية. Git يمر عبر Process API لا shell، ويعطل hooks،
ويقبل `file/https/ssh/git` فقط، ويكتب symlinks كنص عبر `core.symlinks=false`.
cache Git في `.takween/packages/<commit>` ويعاد فرض checkout وتنظيفه قبل الاستخدام.

## المؤجل صراحة

- public registry أو service للنشر؛
- تنزيل archive عبر الشبكة أو حل اسم registry؛
- tokens وتوقيع metadata وnamespace ownership وyank policy؛
- lifecycle/install scripts؛
- تحويل `baalib` إلى حزمة عادية.

الأوامر المستقبلية `أضف` و`احذف` و`حدّث` و`ثبت` و`انشر` لا تعد منفذة بهذه
المرحلة. الأوامر العربية الحالية تعمل على Windows وLinux بفضل عقد argv Unicode
في Baa، ولا تحتاج alias لاتينيا؛ تبقى aliases الإنجليزية للتوافق فقط.
