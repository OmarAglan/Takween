# معمارية الحزم في تكوين

> **الحالة:** تصميم مرحلي؛ لا يوجد سجل عام في Takween 0.1.

## حدود الملكية

- **Baa:** اللغة وABI وامتدادات `.baa/.baahd` و`baalib` وعقود المصرّف.
- **Takween:** الحل والقفل والجلب وcache وvendor والبناء والنشر.
- **السجل:** metadata وarchives غير القابلة للتغيير وملكية namespace والفهرسة.
- **Qalam:** واجهة مرئية لهذه العمليات؛ لا ينفذ resolver مستقلا.

`baalib` ليست حزمة registry. تشحن مع Baa SDK وتتبع توافق المصرّف. المكتبات
العليا الرسمية مثل JSON وHTTP وCLI والاختبار يمكن أن تنشر كحزم عادية مستقلة.

## ترتيب التنفيذ

1. اعتماديات `مسار` داخل الجهاز ومساحة العمل.
2. اعتماديات Git مثبتة بـ commit، لا branch متحرك في ملف القفل.
3. resolver Semantic Versioning و`تكوين.قفل` وcache معنون بالمحتوى.
4. archive محلي وvendor/offline verification.
5. عميل سجل تجريبي.
6. نشر وسجل عام بعد ثبات العقود.

## ملف القفل

`تكوين.قفل` ملف مولد وحتمي يحتوي لكل عقدة:

- الاسم والنسخة الدقيقة؛
- المصدر الدقيق وcommit عند Git؛
- SHA-256 لمحتوى archive؛
- الاعتماديات الانتقالية؛
- قيود Baa والهدف المختارة؛
- إصدار schema وresolver الذي أنشأ الملف.

التطبيقات وworkspaces تلتزم ملف القفل. المكتبات تنشر مجال الإصدارات ولا تنشر
اختيار المستهلك النهائي، مع استخدام lock محلي لاختبارات maintainer.

## الهوية العربية والأمان

- تطبع الأسماء إلى Unicode NFC قبل المقارنة والتخزين.
- تمنع الحركات والتطويل وbidi controls في هوية الحزمة، مع السماح بها في الوصف.
- يمنع خلط العربية واللاتينية داخل مقطع اسم واحد لتقليل أسماء الانتحال.
- namespace يفصل المالك عن الحزمة، والسجل يحتفظ بمعرف داخلي ASCII ثابت.
- الإصدار المنشور immutable؛ السحب يضيف تحذيرا ولا يعيد استخدام الرقم.
- لا توجد lifecycle scripts ضمنية في v1.
- الجلب يتحقق من TLS وhash القفل قبل فك archive، ويفك داخل جذر مؤقت يمنع
  absolute paths و`..` وsymlink escape.

## أوامر CLI المخططة

```text
تكوين أضف سلاسل@^2.1
تكوين احذف سلاسل
تكوين حدّث
تكوين ثبت
تكوين ثبت --مقفل
تكوين تحقق --بدون_شبكة
تكوين انشر --تجريبي
```

aliases الإنجليزية (`add`, `remove`, `update`, `install`, `verify`, `publish`)
مقبولة في CLI فقط.
